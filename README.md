# mftik-docs

Public technical docs for [MFTIK](https://github.com/lynxlinkage/mftik), published at [docs.mftik.com](https://docs.mftik.com).

This repo is a [VitePress](https://vitepress.dev/) site. Source lives under `docs/`. Product code is [lynxlinkage/mftik](https://github.com/lynxlinkage/mftik); marketing is [mftik.com](https://mftik.com).

```bash
npm install
npm run docs:dev    # local preview
npm run build       # static output → docs/.vitepress/dist
```

Pages deploy from `main` via GitHub Actions.
